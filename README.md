# Padlet Share

Windows용 패들렛 보드·샌드박스 생성 및 제작자 공유 도우미입니다.

## 포터블 실행·설치와 업데이트

[최신 설치파일 다운로드](https://github.com/jjiseok26/padlet-share-releases/releases/latest)

- 설치 없이 사용할 때는 `PadletShare-Portable.exe` 하나를 내려받아 실행하세요.
- 설치형은 `PadletShare-Setup-버전.exe`를 사용하세요.
- v1.7.0부터 포터블과 설치형 모두 새 정식 버전을 자동 확인·다운로드합니다.
- 다운로드한 업데이트는 앱을 정상 종료할 때 적용됩니다. 포터블은 원래 EXE의 이름과 위치를 유지해 교체하며 설치형으로 바뀌지 않습니다. 진행 중인 작업을 강제로 중단하지 않습니다.
- v1.6.0 이하 기존 포터블 사용자는 v1.7.0 포터블로 한 번 수동 교체하세요. 이후에는 자동 업데이트됩니다.
- 포터블 자동 교체에는 실행 폴더의 쓰기 권한과 여유 공간이 필요합니다.
- 로그인 상태와 생성 기록은 사용 중인 Windows 사용자 계정에 저장됩니다. 이 저장소에는 업로드되지 않습니다.

이 저장소는 설치파일 및 자동 업데이트 파일의 배포 전용 공간입니다.
